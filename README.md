ROXY Shop Account — updated flow

1. ZIP extract করে পুরো roxy-shop-account ফোল্ডারটি VS Code-এ খুলুন।
2. index.html ব্রাউজারে চালান। CSS ডিজাইন HTML-এর মধ্যেই আছে, তাই আলাদা CSS ফাইল দরকার নেই।
3. প্রথম স্ক্রিনে ROXY লেখা ও password box থাকবে। ডিফল্ট পাসওয়ার্ড: 1234।
4. পাসওয়ার্ড পরিবর্তন করতে index.html-এ `const PASSWORD = "1234";` লাইনটি বদলান।
5. লগইন করার পর date field-এ আজকের তারিখ অটো থাকবে। আজকের হিসাব খুলতে Create / Open Page চাপুন। পুরোনো তারিখ বেছে একই বাটনে চাপলে সেই দিনের হিসাব খুলবে এবং edit করা যাবে।
6. Sales Page ও Due Page একই তারিখের জন্য থাকবে। প্রতিটি পরিবর্তন অটো-সেভ হবে। কেউ বাকি পরিশোধ করলে Due Page-এ সেই এন্ট্রির Delete বাটনে চাপুন।
7. এই সংস্করণে ডেটা একই ব্রাউজার/ডিভাইসের localStorage-এ থাকে। অন্য ডিভাইসে শেয়ার করতে online database লাগবে। কোডের ভেতরের পাসওয়ার্ড শক্তিশালী নিরাপত্তা নয়।
8. এখানে আসল লোগো ফাইল দেওয়া হয়নি, তাই ROXY লেখা ব্যবহার করা হয়েছে; আসল লোগো দিলে পরে বসানো যাবে।
